# Aether Launcher

**Aether Launcher** — нативный, легковесный и высокопроизводительный лаунчер Minecraft нового поколения, написанный на **чистом C++ (Win32 API + GDI+)** без зависимостей от Chrome, Edge, WebView2, Electron или тяжелых браузерных движков. Лаунчер отличается мгновенным запуском (< 20 мс), потреблением памяти всего ~15 МБ, нулевой нагрузкой на процессор во время игры, красивой векторной графикой, удобным вводом никнейма прямо в главном меню и надежным запуском игры.

## Ключевые возможности

- 🚀 **100% Нативный C++ Windows GUI**: размер бинарника около 771 КБ. Никаких сторонних браузеров, Chrome, Edge или Node.js. Запуск через нативное Win32 GUI окно со сглаживанием GDI+, двойной буферизацией (60 FPS без мерцаний), темной темой Windows DWM Immersive Dark Mode (без белых рамок заголовка окна) и аппаратным рендерингом.
- 🎨 **Четкие векторные иконки и темная тема**: все иконки (контейнеры, моды, логи, бэкапы, настройки, поиск, 3D изометрический куб Minecraft) отрисованы векторными путями GDI+. Устранена белая рамка заголовка благодаря интеграции с Windows Desktop Window Manager (`DwmSetWindowAttribute`).
- ⚡ **Выбор загрузчика модов (Mod Loader Selector)**:
  - Удобное отдельное меню выбора загрузчика прямо на панели запуска: **Vanilla**, **Fabric**, **Forge**, **NeoForge**, **Quilt**.
  - Настройка загрузчика для каждого контейнера и сохранение в конфигурации.
- ⚙️ **Полная настройка на уровне Java и JVM флаги (как в Prism/MultiMC)**:
  - Свободный ввод любых кастомных аргументов JVM (`-XX:... -D...`) прямо во вкладке настроек.
  - Быстрые пресеты сборщика мусора: **Aikar's Flags** (рекомендовано для Minecraft), **ZGC (Low-Latency)**, **Shenandoah GC**, **Standard G1GC** и **Пользовательский**.
  - Выбор пути к исполняемому файлу Java (`javaw.exe`) с кнопками автоматического поиска и тестирования версии.
  - Настройка разрешения окна игры (Ширина × Высота), полноэкранного режима и режима пониженной нагрузки на процессор.
- 🧩 **Бесконечный каталог Modrinth с безопасной установкой**:
  - В каталоге отображается начальная партия из 20 модов; следующая партия автоматически подгружается при прокрутке к концу списка — без страниц и миниатюрных строк.
  - Остаётся только поиск модов по названию: установка из произвольной ссылки или slug вне результатов каталога отключена.
  - Результаты и версия для загрузки строго подбираются под выбранные в активном контейнере Minecraft и загрузчик модов.
  - Вместе с модом автоматически скачиваются все обязательные зависимости Modrinth; необязательные и встроенные зависимости не дублируются.
  - Просмотр подробного описания любого мода, автора, ссылок и поддерживаемых версий.
- 📜 **Полный список официальных релизов Minecraft**:
  - Лаунчер загружает список release-версий прямо из манифеста Mojang; если сеть недоступна, остаётся локальный список популярных версий.
  - В создании контейнера версии Minecraft выбираются отдельно от загрузчика (Vanilla, Fabric, Forge, NeoForge или Quilt).
- 📦 **Один контейнер по умолчанию и удобный выбор**:
  - По умолчанию создан ровно один профиль (*Minecraft 1.21.1 Vanilla*).
  - Удобный выпадающий список активного профиля прямо в шапке окна и в карточках контейнеров.
  - Кнопка «+ Создать контейнер» открывает форму с отдельными полями названия, версии Minecraft и загрузчика; профиль сразу сохраняется и становится активным.
  - Переименование, вход Microsoft и создание профилей используют настоящие модальные окна: «ОК», «Отмена», Enter, Escape и крестик корректно применяют действие или закрывают окно.
- 🎚️ **Глобальное управление оперативной памятью (ОЗУ)**:
  - Плавный интерактивный ползунок выделения памяти (от 1024 МБ до 16384 МБ), применимый ко всем контейнерам.
  - Поле прямого числового ввода для задания любого произвольного объема памяти в МБ.
  - Быстрые пресеты (2 GB, 4 GB, 6 GB, 8 GB, 12 GB, 16 GB).
- 👤 **Никнейм прямо в главном меню**: ввод игрового никнейма вынесен на панель запуска в главном меню. Просто введите ник, выберите версию и нажмите «Играть».
- 🎮 **Надёжный запуск Minecraft**:
  - Автоматическое обнаружение установленной Java (Java 8, 16, 17, 21+ в системных путях, реестре и `%APPDATA%`).
  - Автоматическая загрузка официального `client.jar`, полного списка релизов и метаданных Mojang через WinINet/WinHTTP при их отсутствии.
  - Загрузка библиотек повторяется через несколько CDN/Maven-зеркал; JAR проверяются по SHA-1 и ZIP-сигнатуре, поэтому неполный файл не попадёт в classpath.
  - Формирование полного classpath и корректных аргументов JVM (Xms/Xmx, пресеты сборщика мусора G1GC/ZGC, пути библиотек и нативных файлов).
  - Запуск через `CreateProcessW` с асинхронным перехватом стандартного вывода (stdout/stderr) в реальном времени.
- 🛠️ **Интеллектуальная диагностика крашей**:
  - Анализ логов игры на лету: распознавание несовместимости Java, нехватки оперативной памяти (OOM), ошибок драйверов видеокарт и повреждённых модов.
  - Вывод понятных рекомендаций на русском языке прямо во вкладке «Логи».
  - Подробный UTF-8 журнал (этапы проверки Java, загрузки и подготовки, вывод и код завершения Java) сохраняется в `<путь хранения>\logs\launcher.log`; токены аккаунта в журнал не записываются.
- 📦 **Нативный установщик**:
  - Быстрая установка через `Aether Installer.exe`.
  - Автоматическое создание ярлыков на рабочем столе и в меню «Пуск».

## Архитектура проекта

```
Aether/
├── src/
│   ├── cpp/                       # Нативный C++ движок лаунчера
│   │   ├── config.hpp             # Конфигурация и профили (%APPDATA%\AetherLauncher\config.ini)
│   │   ├── minecraft_launcher.hpp # Заголовочный файл запуска Minecraft и загрузчика
│   │   ├── minecraft_launcher.cpp # Java сканер, загрузка с Mojang CDN, запуск процесса, анализ крашей
│   │   ├── launcher_main.cpp      # Win32 GDI+ интерфейс (векторные иконки, поиск модов, слайдер RAM, док)
│   │   └── installer_main.cpp     # Нативный установщик Windows
│   └── ...                        # TypeScript/Node.js библиотека и тесты
├── test/                          # Автоматические тесты (20 тестов)
├── Aether.exe                     # Скомпилированный нативный лаунчер (~771 КБ)
├── Aether Installer.exe           # Скомпилированный нативный установщик (~169 КБ)
└── release/                       # Пакеты релизов (Aether Update.zip)
```

## Сборка и тестирование

### Компиляция нативного C++ лаунчера
Для сборки под Windows используется `zig c++`:
```bash
# Сборка лаунчера Aether.exe
zig c++ -target x86_64-windows -Wl,--subsystem,windows -Os src/cpp/launcher_main.cpp src/cpp/minecraft_launcher.cpp -lgdiplus -lgdi32 -lcomctl32 -lcomdlg32 -lwininet -lws2_32 -lshlwapi -lshell32 -ldwmapi -lcrypt32 -lwinhttp -o Aether.exe

# Сборка установщика Aether Installer.exe
zig c++ -target x86_64-windows -Wl,--subsystem,windows -Os src/cpp/installer_main.cpp -lshell32 -o "Aether Installer.exe"
```

### Запуск тестов
```bash
npm test
```
Все 20 тестов валидируют структуру PE-бинарников, логику запуска, сканер Java, векторные иконки, слайдер памяти, поиск модов и автообновление.
