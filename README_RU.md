# Aether Launcher

**Aether Launcher** — современный, легковесный и высокопроизводительный лаунчер Minecraft нового поколения с практически нулевой нагрузкой на процессор (< 0.1% в простое, 0.00% во время игры), изолированными контейнерами, прямой интеграцией с Modrinth, умной системой диагностики крашей, мониторингом серверов и надежными автообновлениями.

## Ссылки

- **GitHub репозиторий**: https://github.com/Sqikpeek/Aether
- **Релизы**: https://github.com/Sqikpeek/Aether/releases
- **Установщик**: откройте последний релиз и скачайте `Aether Installer.exe`
- **Пакет обновления**: для установки и обновлений используется `Aether Update.zip`

## Возможности

- 🚀 **Сверхбыстрый движок и 0% нагрузки на ЦП**: переписан с нуля на событийно-ориентированную асинхронную архитектуру. Запуск за 50 мс, отсутствие тяжёлых циклических опросов `tasklist` и экономный фоновый режим.
- 📦 **Изолированные контейнеры**: создавайте независимые профили под разные версии Minecraft, сборки модов и загрузчики.
- ⚡ **Поддержка всех загрузчиков**: Vanilla, Fabric, Quilt, Forge и NeoForge.
- 🧩 **Интеграция с Modrinth v2**: поиск, просмотр и установка модов, датапаков, ресурспаков и плагинов в 1 клик с автоматической фильтрацией под версию контейнера.
- 🔄 **Быстрое переключение модов**: мгновенное включение и отключение модов (`.jar` <-> `.jar.disabled`) без удаления и повторного скачивания.
- 💾 **Общие миры (Shared Saves)**: поддержка единого каталога сохранений между контейнерами без дублирования данных (с использованием безопасных Directory Junctions на Windows и symlinks на POSIX).
- ☕ **Автоподбор Java и совместимость**: автоматическое сканирование установленных сред выполнения Java (Adoptium, Oracle, Corretto, Zulu, Microsoft OpenJDK), определение разрядности и валидация совместимости с версией Minecraft (Java 8 для 1.16.5, Java 17 для 1.18–1.20.4, Java 21+ для 1.20.5+).
- 🛠️ **Умная диагностика крашей**: автоматический анализ отчетов об ошибках и логов с распознаванием несовместимой Java, нехватки оперативной памяти (OOM), отсутствующих зависимостей модов и конфликтов с готовыми инструкциями по исправлению.
- 📡 **Мониторинг серверов (Server Ping)**: встроенная проверка онлайна, пинга (мс), версии и форматированного MOTD до запуска игры.
- 📸 **Снимки миров и настроек (Backups)**: создание резервных копий сохранений и конфигов в 1 клик перед тестированием новых модов.
- 🏎️ **Готовые пресеты флагов JVM**: флаги Aikar (G1GC без фризов), Low RAM (для слабых ПК) и Generational ZGC для Java 21+.
- 🎨 **Темы оформления и стильный перелив кнопки «Играть»**: 6 тем (Void Purple, Crimson Red, Cyberpunk Cyan, Emerald Green, Amber Gold, Nordic Blue). Аппаратно-ускоренный перелив строго следует цветам темы и автоматически встает на паузу для экономии ресурсов.
- 🌐 **Мгновенная смена языка**: русский и английский интерфейс без перезагрузки.
- 🔄 **Надежное многоуровневое автообновление**: автоматический переход по цепочке GitHub API -> HTTP-редирект -> raw-манифест -> кэш с потоковой валидацией контрольной суммы SHA-256 и безопасной заменой файлов.

## Быстрый старт и запуск

### Запуск из исходного кода
```bash
# Установка зависимостей
npm install

# Запуск тестов
npm test

# Сборка проекта
npm run build

# Запуск лаунчера
npm start
```

### Запуск в режиме разработки с живым предпросмотром
```bash
npm run dev
```

Интерфейс лаунчера откроется по адресу `http://localhost:3000`.

- `Aether Update.zip` — пакет лаунчера для установки и автообновления.
