# Aether Launcher

**Aether Launcher** — нативный, легковесный и высокопроизводительный лаунчер Minecraft нового поколения, написанный на **чистом C++ (Win32 API)** без зависимостей от Chrome, Edge, WebView2, Electron или тяжелых браузерных движков. Лаунчер отличается мгновенным запуском (< 20 мс), потреблением памяти всего ~15 МБ, нулевой нагрузкой на процессор во время игры, удобным вводом никнейма прямо в главном меню и надежным запуском игры.

## Ключевые возможности

- 🚀 **100% Нативный C++ Windows GUI**: размер бинарника всего ~240 КБ. Никаких сторонних браузеров, Chrome, Edge или Node.js. Запуск через нативное Win32 GUI окно с тёмной темой и аппаратным рендерингом GDI/ComCtl32.
- 👤 **Никнейм прямо в главном меню**: ввод игрового никнейма вынесен на панель запуска в главном меню (а не спрятан в настройках). Просто введите ник, выберите версию и нажмите «Играть».
- 🎮 **Надёжный запуск Minecraft**:
  - Автоматическое обнаружение установленной Java (Java 8, 16, 17, 21+ в системных путях, реестре и `%APPDATA%`).
  - Автоматическая загрузка официального `client.jar` и метаданных версий с официального CDN Mojang (`piston-meta.mojang.com`) через WinINet при их отсутствии.
  - Формирование полного classpath и корректных аргументов JVM (Xms/Xmx, пресеты сборщика мусора G1GC/ZGC, пути библиотек и нативных файлов).
  - Запуск через `CreateProcessW` с асинхронным перехватом стандартного вывода (stdout/stderr) в реальном времени.
- 🛠️ **Интеллектуальная диагностика крашей**:
  - Анализ логов игры на лету: распознавание несовместимости Java, нехватки оперативной памяти (OOM), ошибок драйверов видеокарт и повреждённых модов.
  - Вывод понятных рекомендаций на русском языке прямо во вкладке «Логи».
- 📡 **Встроенный мониторинг серверов (SLP)**:
  - Пинг серверов на чистых Winsock сокетах.
  - Отображение статуса, задержки в мс, количества игроков и версии сервера.
- ⚙️ **Гибкие настройки**:
  - Выбор выделяемой памяти (RAM от 2 ГБ до 16 ГБ).
  - Выбор версии Java и пользовательских аргументов JVM.
  - Настройки директории игры (`%APPDATA%\AetherLauncher`).
- 📦 **Нативный установщик**:
  - Быстрая установка через `Aether Installer.exe`.
  - Автоматическое создание ярлыков на рабочем столе и в меню «Пуск».

## Архитектура проекта

```
Aether/
├── src/
│   ├── cpp/                       # Нативный C++ движок лаунчера
│   │   ├── config.hpp             # Конфигурация и профили (%APPDATA%\AetherLauncher\config.ini)
│   │   ├── minecraft_launcher.hpp # Заголовочный файл запуска Minecraft и загрузчика
│   │   ├── minecraft_launcher.cpp # Java сканер, загрузка с Mojang CDN, запуск процесса, анализ крашей
│   │   ├── server_pinger.hpp      # Пинг серверов через сокеты Winsock
│   │   ├── launcher_main.cpp      # Win32 интерфейс лаунчера (главное меню, логи, серверы, настройки)
│   │   └── installer_main.cpp     # Нативный установщик Windows
│   └── ...                        # TypeScript/Node.js библиотека и тесты
├── test/                          # Автоматические тесты (15 тестов)
├── Aether.exe                     # Скомпилированный нативный лаунчер (~240 КБ)
├── Aether Installer.exe           # Скомпилированный нативный установщик (~173 КБ)
└── release/                       # Пакеты релизов (Aether Update.zip)
```

## Сборка и тестирование

### Компиляция нативного C++ лаунчера
Для сборки под Windows используется `zig c++`:
```bash
# Сборка лаунчера Aether.exe
zig c++ -target x86_64-windows -Wl,--subsystem,windows -Os src/cpp/launcher_main.cpp src/cpp/minecraft_launcher.cpp -lgdi32 -lcomctl32 -lwininet -lws2_32 -lshlwapi -o Aether.exe

# Сборка установщика Aether Installer.exe
zig c++ -target x86_64-windows -Wl,--subsystem,windows -Os src/cpp/installer_main.cpp -lshell32 -o "Aether Installer.exe"
```

### Запуск тестов
```bash
npm test
```
Все 15 тестов валидируют структуру PE-бинарников, логику запуска, сканер Java, парсинг аргументов JVM и автообновление.
